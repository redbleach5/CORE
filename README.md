# CORE

# HDC-MVP Core: Нейро-символьное ядро для надежного ИИ

Это ядро проекта HDC-MVP-RU. Оно представляет собой **нейро-символьный движок**, сочетающий **голографические плотные вычисления (HDC)** и **векторные индексы (FAISS)** для создания **объяснимого, контролируемого и логически обоснованного** ядра интеллектуальных систем.

В отличие от "черных ящиков" LLM, это ядро оперирует **явно заданными знаниями** и **математически обоснованными операциями**, что открывает возможности для создания ИИ с новым качеством взаимодействия и доверия.

## Уникальные возможности (Потенциал)

1.  **Объяснимый ИИ (XAI):** Каждый ответ или вывод можно проследить до конкретных фактов в базе знаний и логических операций, выполненных над ними ("Provenance"). Вы всегда знаете *почему* система дала такой ответ.
2.  **Надежный RAG без галлюцинаций:** Ядро служит как *источник истины*. Интеграция с LLM (RAG) гарантирует, что генерация основана на *ваших* данных, а не на общем знании LLM, минимизируя галлюцинации и обеспечивая актуальность.
3.  **Глубокие логические рассуждения:** Поддержка **многоходового поиска (Multi-hop retrieval)** позволяет отвечать на сложные, составные вопросы, требующие цепочки логических умозаключений ("Где работает жена брата Ивана?").
4.  **Контролируемость и безопасность:** Так как знания и логика явно заданы, легче контролировать поведение системы, исключать нежелательные ответы и внедрять бизнес-правила.
5.  **Агент с внутренним мышлением:** Может служить "мозгом" для ИИ-агента, выполняя роль *долговременной памяти* и *движка логического вывода*, которому можно делегировать части сложных задач.

## Структура

- `service/`: Основной сервис HDCService, координирующий работу всех компонентов.
- `store/`: Определения типов и логика хранения сущностей, предикатов, фактов и контекстов.
- `blocks/`: Управление блоками памяти для сущностей.
- `index/`: Бинарный индекс FAISS для быстрого поиска.
- `hdc/`: Утилиты для работы с гипервекторами и генераторы псевдослучайных чисел.

## Сценарии использования (Потенциал в действии)

- **Корпоративные чат-боты и помощники:** Ответы на вопросы строго на основе внутренней документации, политик и базы знаний компании.
- **Юриспруденция / Медицина:** Системы поддержки принятия решений, где критически важно объяснить логику вывода и опираться на точные, проверенные источники.
- **Научные исследования:** Анализ сложных сетей знаний, гипотез и связей между сущностями с возможностью воспроизведения логики.
- **ИИ-агенты:** Ядро как модуль памяти и логического планирования для агентов, решающих сложные, многоступенчатые задачи.

## Интеграция

Ядро предназначено для интеграции в более крупные системы. Его можно использовать как:
- Самостоятельный движок поиска и рассуждений.
- Компонент RAG-системы для усиления LLM знаниями.
- Модуль памяти и логики для ИИ-агентов.

Для запуска необходима среда Node.js и зависимости, указанные в основном `package.json`.
